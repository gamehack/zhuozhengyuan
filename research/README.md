# Research and Source Register

The source register is research metadata, not a license grant. Publicly accessible pages, maps, drawings, and photographs may remain copyrighted.

## Rules
- Add every source to references.csv before using it in a model decision.
- Record access date, source type, publisher, URL, and permission status.
- Prefer official conservation, garden-management, UNESCO, and measured architectural sources.
- Keep original files outside the public repository unless redistribution rights are confirmed.
- For field captures, record date, approximate location/viewpoint, camera direction, and permission conditions.
- If sources disagree, create an explicit research note and preserve both claims.

## Current findings
- The official Suzhou government description identifies eastern, central, western, and southern residential sections and gives an approximate total area of 51,950 m².
- UNESCO's property map lists the garden as 5.195 ha and provides a geographic reference coordinate.
- UNESCO nomination materials describe the garden's water, rock, plant, and building composition and point to historical survey literature.
- The exact current site boundary, local coordinate datum, detailed current measured plan, and object-level dimensions have not yet been established in this repository.
- Public sources disagree on the fraction of the garden occupied by water. This conflict is recorded and must not be used as geometry input until reconciled.

See references.csv, RESEARCH_STATUS.md, and data/site-baseline.json. The 2026 survey-data commentary is treated as a research warning, not an official determination.
