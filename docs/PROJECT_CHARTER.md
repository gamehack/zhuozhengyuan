# Project Charter

## Mission
Create an evidence-led, dimensionally coherent digital reconstruction of the Humble Administrator's Garden (拙政园) as it exists today, then deliver a high-fidelity real-time Windows PC walkthrough.

This is a digital-heritage reconstruction project, not a stylized garden game. Visual quality must not override spatial and historical accuracy.

## Baseline and scope
- Time baseline: present-day garden; record the date of each field capture and source.
- Geographic scope: eastern section, central section, western section, and southern residential area.
- Core elements: site boundary, terrain, water bodies and edges, islands, bridges, paths, corridors, halls, pavilions, rockeries, trees, bamboo, shrubs, paving, walls, windows, plaques, and other visible details.
- Initial runtime target: Windows PC.
- Initial authoring target: Blender 5.2.4 LTS.
- Initial real-time engine target: Unreal Engine 5.8.4.

## Accuracy commitments
1. Every real-world modeled asset must have a stable ID.
2. Every asset must record source references and an evidence grade.
3. Unknown dimensions remain unknown; do not substitute plausible-looking invented measurements.
4. Estimates must be labeled as estimates and must not be promoted to measured facts.
5. Conflicting sources must be recorded as conflicts.
6. The project coordinate origin and local axes will be defined only after a reliable site plan or survey reference is selected.
7. Public availability does not imply permission to redistribute source photographs, maps, or drawings.

## Out of scope for P0
- Full garden modeling or historical reconstruction of the Ming/Qing garden.
- Public redistribution of source imagery without rights clearance.
- Multiplayer, VR, mobile, browser runtime, or game mechanics.
- Purchasing new hardware.
- Automated UE packaging before local engine installation and project verification.

## Definition of success
- P0: a synthetic, explicitly labeled test scene is generated by Blender Python, saved as BLEND, exported as FBX, imported into UE 5.8.4 with verified scale and axes, and used in a minimal Windows walkthrough.
- P1: a measured or source-traceable 1:1 site blockout covers the complete garden.
- P2: a selected central-garden area is reconstructed to high visual fidelity and reviewed against fixed real-world viewpoints.
- Later phases: remaining areas, detailed assets, lighting, vegetation, water, sound, performance, and final packaging are completed incrementally.
